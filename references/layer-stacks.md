# 常见类型的分层起点

这些只是起点，不是规定。每一行都要回到 SKILL.md 第 1 节，用"玩家此刻要读出什么"重新验证。

- 层按**显眼优先级**从低到高排列，不是按绘制顺序。
- "专属档"指只留给某一种信号的那一段显眼通道。一个项目可以有多个专属档，但每一档只对应一种含义。

| 类型 | 层（低 → 高） | 专属档的常见选择 | 典型的崩溃方式 |
|---|---|---|---|
| 俯视角 MOBA / ARPG | 装饰地表 → 地形边界 → 角色/怪物 → 技能与范围指示 → UI | 最高明度给技能；前摇和范围用固定的颜色加形状 | 掉落物、环境光和技能抢同一档；大片 AOE 盖住角色 |
| 3D 动作 / Boss 战 | 场景 → 小怪 → Boss 身体（体型大时当作画布）→ 玩家角色 → 前摇部位与地面落点指示 → 命中反馈 → UI | 前摇用场景色族之外的色相，加固定的形状和起手方式 | 前摇和场景同一色族；玩家自己的命中火花盖住下一击；Boss 抬手跑出画面 |
| 横版平台 | 远景视差 → 装饰 → 可站立面与危险物 → 角色/敌人 → 弹幕 → UI | 危险物用一种固定的色相加形状，全游戏不变 | 远景对比太高，分不清能不能站；装饰和平台用同一种材质 |
| FPS / TPS | 远景 → 场景与掩体 → 可交互物 → 敌人 → 弹道/命中反馈 → 准星与 HUD | 敌人的剪影与明度对比（描边、轮廓光）；命中和受击反馈 | 写实材质的高频细节淹没敌人；bloom 吞掉弹道 |
| 战棋 / 策略 | 地形底色 → 地形类型 → 单位 → 选中/可行动状态 → 移动、攻击、危险范围 → UI | 当前选中与可行动状态；危险范围用边缘加纹样 | 范围色块铺得太大太艳；地形类型只靠色相区分 |
| 塔防 | 地面 → 路径 → 范围贴花 → 塔 → 弹道本体（小而短）→ 敌人 → 命中瞬间 → 漏怪提示 → UI | 敌人专属一种色相；最高明度只给命中瞬间 | 后期塔和特效满屏，路径与敌人消失；升级后的塔越来越亮；减速区叠加后越来越亮 |
| 弹幕 / 割草 | 地面 → 掉落物 → 己方弹幕 → 敌人 → 敌方弹幕 → 玩家判定点 → UI | 敌方弹幕独占一种明度与色相组合；判定点永远可见 | 己方弹幕的数量淹没敌方弹幕；经验宝石铺满地面 |
| 挖掘 / 采矿沙盒 | 背景 → 普通方块 → 有玩法含义的方块（矿物、危险、导电）→ 角色/工具 → 危险与状态提示 → UI | 危险方块用固定的发光或色相，只在激活时出现 | 方块材质的纹理比角色还吵；发光矿物和危险提示用了同一档；地下露出天空（多半是穿帮） |
| 三消 / 消除 | 背景 → 棋盘底板 → 棋子（靠形状区分，不只靠颜色）→ 可消除提示 → 消除反馈与飘字 → 道具与目标 UI | 思考阶段把最强的通道给提示；结算阶段给消除反馈 | 反馈和通知挤进思考阶段；循环动画抢走提示的运动通道；棋子在灰度下分不开 |
| 解谜 | 背景 → 静态结构 → 可操作元素 → 状态变化与提示 → UI | 可操作元素的一致标记（统一的高光、描边或动效） | 两个方向都会出问题：提示过强等于给出答案；提示被装饰和反馈淹没 |
| 竞速 | 天空/远景 → 赛道外 → 赛道边界 → 对手/障碍 → 速度特效 → HUD | 赛道边界和弯道提示的明度差 | 速度特效和天空光把边界冲淡 |
| 恐怖 / 潜行 | 黑暗环境 → 可走区域的微弱提示 → 可交互物 → 威胁 → UI（极简） | "亮"本身就是专属档；各种亮点再靠形状、高度、动态区分 | 为了可读性把整体提亮，氛围崩掉；或者暗到连路都找不到 |
| 卡牌 / 回合制 | 背景 → 牌桌与区域 → 卡牌 → 可打出/可选中状态 → 结算动画 | 可行动状态（发光边框、抬起） | 卡面插画的对比高过状态标记，看不出哪张能出 |

## 阶段切换

层级随阶段变化，每个阶段各排一次：

- 战棋选目标时，压暗非候选单位，让 HUD 退后。
- 卡牌分我方回合和对方回合。
- 动作游戏分探索和战斗。
- 玩家不能操作的结算动画里，特效可以放开；交还控制之前收回。
- 和当前决策无关的通知，不要排队挪进玩家思考的阶段。

反馈多、阶段分明的游戏，用一张"元素 × 阶段"的表落实：每个元素在每个阶段该不该出现、该不该动、用哪一档。最容易漏的就是"某个元素在某个阶段不该动"。
